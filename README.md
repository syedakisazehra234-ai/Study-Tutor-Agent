# 📚 Study Tutor Agent

An AI-powered personalized study tutor built with Streamlit,
CrewAI and Groq.

## Features

- Personalized study sessions
- Difficulty adaptation
- Exam-focused explanations
- Practice questions
- MCQs
- Study planning
- Agent tools
- CrewAI memory
- Groq GPT-OSS-120B

## Tech Stack

- Python
- Streamlit
- CrewAI
- Groq
- Hugging Face Sentence Transformers

## Architecture

Streamlit → CrewAI Agent → Tools + Memory → Groq LLM

## Environment Variable

The application requires:

GROQ_API_KEY
